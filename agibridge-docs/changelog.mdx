## Changelog policy

- Every release gets an entry, even patch-level fixes.
- Tier soft caps and retention windows: increases are silent (no notice required), decreases require 60-day email notice.
- Breaking API changes ship with a migration guide on the same release. Old endpoints stay valid for the documented deprecation window (60 days minimum per `marketing/site-copy/docs-structure.md` §4).
- `embodied-data` lib version bump → entry here even if no agibridge-level change.
