Returns the full record for a single job, including the verification report once status is `done`. The dashboard polls this endpoint per-job at 2 seconds while active, 5 seconds while queued.

**Endpoint signature**: `GET /api/v1/jobs/{job_id}` — cited from `dispatches/D4_specs.md` §3 amendment #3 line 58.

## Authentication and isolation

Clerk JWT in `Authorization: Bearer ...` header. Backend enforces `(job_id, org_id)` tuple lookup — see `dispatches/D4_specs.md` §3 amendment #3 line 58 ("backend MUST enforce `(job_id, org_id)` tuple lookup"). A cross-org `job_id` returns 404, not 403 — see [R3 isolation](/concepts/r3-isolation).

## Path parameters

| Param | Type | Description |
|---|---|---|
| `job_id` | string | Job identifier returned from `presign-upload` / `create-job`. |

`progress.fraction` is approximate; episode boundaries are deterministic, intra-episode progress is interpolated.

## Error responses

| Status | Code | When |
|---|---|---|
| 401 | `unauthorized` | Missing or invalid Clerk JWT |
| 404 | `job_not_found` | `job_id` does not exist or belongs to a different org (R3 invariant — no leak) |
| 429 | `rate_limited` | More than 30 req/min on this endpoint (per `dispatches/D4_specs.md` §3 amendment #2) |

```python Python
import httpx
import time

def poll_until_done(job_id: str, clerk_jwt: str, timeout_seconds: int = 1800):
    headers = {"Authorization": f"Bearer {clerk_jwt}"}
    deadline = time.monotonic() + timeout_seconds

    while time.monotonic() < deadline:
        response = httpx.get(
            f"https://api.agibridge.com/api/v1/jobs/{job_id}",
            headers=headers,
        )
        response.raise_for_status()
        job = response.json()

        if job["status"] in {"done", "failed", "cancelled"}:
            return job

        # Match dashboard cadence: 2s active, 5s queued
        sleep_s = 5 if job["status"] == "queued" else 2
        time.sleep(sleep_s)

    raise TimeoutError(f"Job {job_id} did not complete in {timeout_seconds}s")

final_job = poll_until_done(job_id, clerk_jwt)
if final_job["status"] == "done":
    print("Conversion succeeded:", final_job["verification_report"])
else:
    print("Conversion failed:", final_job["error"])
```

```typescript TypeScript
async function pollUntilDone(
  jobId: string,
  clerkJwt: string,
  timeoutMs = 1_800_000
): Promise<Job> {
  const deadline = Date.now() + timeoutMs;
  const headers = { Authorization: `Bearer ${clerkJwt}` };

  while (Date.now() < deadline) {
    const response = await fetch(
      `https://api.agibridge.com/api/v1/jobs/${jobId}`,
      { headers }
    );
    if (!response.ok) throw new Error(`get-job ${response.status}`);
    const job: Job = await response.json();

    if (["done", "failed", "cancelled"].includes(job.status)) {
      return job;
    }

    const sleepMs = job.status === "queued" ? 5_000 : 2_000;
    await new Promise((r) => setTimeout(r, sleepMs));
  }

  throw new Error(`Job ${jobId} did not complete in time`);
}
```
